### alvidaa v2.0

**Release Date:** November 9, 2026  
**Since v1.0:** ~91 commits · ~14 merged PRs · 677 files changed · ~69,024 insertions · ~1,283 deletions · 12 contributors

> **The Three Lanes Release.** In v1.0, alvidaa unlocked the front door: pairing over local MQTT without cloud telemetry, finding a sandbox escape through an OS errno, securing a boot-persistent dropbear SSH prompt on a single 50A51HUV unit, and bouncing the browser to a self-hosted canvas page. v2.0 builds the house around that hearth. The headline: **Lane 3 is alive**. Instead of merely redirecting the browser to an external canvas, rooted TVs can now swap the vendor launcher component directly inside the TV's native home engine (`/Launcher` route swap) — unlocking immediate remote response, live HDMI signal detection, genuine application icons, and zero browser chrome. Underneath it, alvidaa has evolved from a single-TV experiment into a multi-architecture federation: 16 model guides spanning five SoC families (MediaTek MTK9602, MTK9603, MTK9618, MTK9900, and Novatek NT72690). A standalone compiled Go daemon (`bridge/`) brings loopback HTTP, WebSockets, and local MQTT broker sessions directly onto the TV without extra hardware. Around it: an automated zero-secret scanner test suite, the Free My TV native port, a live variant switcher, and a strict 9-point integrity check that guarantees verified boot stays green and every modification remains 100% reversible.

### ⚠️ Upgrade notes

- **Documentation & Findings Reorganization:** Single-model finding files previously located at `docs/findings/` have moved into model-specific paths under `docs/models/<model>/<firmware>/findings/` and shared research under `docs/research/`.
- **Single Source of Truth Enforced:** Never hand-edit markdown tables in `README.md` or `TESTED-MODELS.md`. All capability matrix updates must be added to `docs/research/inventory.json` using the strict vocabulary (`working | gated | closed | open | armed | achieved | blocked | untested | n-a`) and rendered via `scripts/gen-inventory.py`.
- **Verified Boot Invariants:** Verified boot remains locked and green. Writes are strictly confined to `/var/local` and volatile memory. Never write to read-only partitions or touch `/OAD` staging directories.
- **Local Address Redaction:** Real LAN IPs in documentation examples have been normalized to placeholders (`<tv-ip>`) to comply with the repo sanitization policy.
